## 💡 What I Care About

### Data Flow
문제가 발생했을 때 오류가 보이는 부분만 수정하지 않고  
**요청 → 비즈니스 로직 → 데이터 저장 → 응답** 흐름을 따라가며 원인을 찾습니다.

### Maintainability
기능 구현뿐 아니라  
**기존 구조에 미치는 영향 · 데이터 정합성 · 예외 상황 · 변경 가능성**을 함께 고려합니다.

### Why, not only How
새로운 기술을 사용할 때 단순히 사용법을 익히기보다  
**왜 필요한지, 어떤 문제를 해결하는지** 이해한 뒤 적용하려고 합니다.
